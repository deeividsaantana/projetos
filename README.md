# Projetos em Python

Este repositório contém projetos desenvolvidos durante meus estudos em programação e Análise e Desenvolvimento de Sistemas.

## 📌 Objetivo
Praticar lógica de programação, automação e desenvolvimento back-end com Python.

## 💻 Projetos

### 🎮 Jogo de Adivinhação
Sistema simples onde o usuário tenta adivinhar um número gerado aleatoriamente.

### 🔢 Conversor de Unidades
Conversão de valores (ex: metros, temperatura, etc).

### ➕ Calculadora Simples
Operações básicas utilizando Python.

### 🌐 Gerador de Site para MEI
Script Node.js que gera uma landing page estática e responsiva a partir de um JSON com os dados de um cliente MEI, pronta para publicar na Vercel ou Netlify. Veja [`gerador-site-mei/README.md`](gerador-site-mei/README.md).

## 🛠️ Tecnologias
- Python
- Node.js
