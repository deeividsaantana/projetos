# Projetos em Python

Exercícios e pequenos programas feitos durante a graduação em Análise e Desenvolvimento de Sistemas (Universidade de Mogi das Cruzes) para praticar lógica de programação em Python.

## Programas

| Arquivo | O que faz |
| --- | --- |
| `jogo_de_adivinhar.py` | Jogo de adivinhar um número de 1 a 100, com dicas de "muito alto/baixo", contagem de tentativas e tratamento de entrada inválida. |
| `progama_de_conversao.py` | Converte euros em reais com duas casas decimais. |
| `soma_conversao_ex.py` | Soma de dois números e conversão de moeda. |
| `exercicios_aula3.py` | Exercícios de entrada, processamento e saída: soma, conversão de moeda e de unidades. |
| `if_else_ex.py` | Estruturas condicionais: maioridade para habilitação e média de notas. |
| `atividadeparanota.py` | Cálculo de salário bruto, desconto e salário líquido, entre outros exercícios avaliativos. |

## Como executar

Requisito: Python 3.

```bash
python jogo_de_adivinhar.py
```
